Design reference

KAYAN TrustGate: visual design system

Calm, dark, high-contrast security-operations look (Linear / Vercel / CrowdStrike Falcon feel). One accent, semantic colors only where state matters, very little text on screen at once. The 3D office is the hero. This file is static HTML/CSS: it shows what to build, not how it behaves.

Rules the implementation must follow

  • Copy the :root tokens from this file's CSS into the app and delete one-off colors, sizes and fonts.
  • One accent color (teal). Green/red/amber/blue are reserved for state (allow / deny / waiting / info). Never decorative.
  • Body text is at least 14px in the console and 16px in Presentation mode. Secondary text must stay at or above 4.5:1 contrast.
  • Use the status vocabulary: ALLOW / DENY / Waiting / Idle / Completed. Never show raw UUIDs or policy strings as main content: truncate, with a copy button.
  • Keep every honesty label: "Hypothesis, not tested", the verbatim illustrative-points disclaimer, "zero policy weight", and the grounding-failure statement in evidence views.
