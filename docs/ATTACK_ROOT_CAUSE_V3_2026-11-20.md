# KAYAN ATT&CK v2 root-cause investigation

**20 November 2026 · Offline forensic reconstruction.** The 0/10 result combines two measured failure modes. The shortlists omitted five BM25 and six hybrid expected occurrences per pass. The model selected every expected ID shown, yet completed zero associated evidence chains. BM25 and hybrid also emitted findings on every inconclusive case. Candidate retrieval alone cannot explain the evidence failures. ### Failure mechanisms ranked by what the run establishes

1. **Missing evidence linkage on every retrieved target.** Outputs provided at most partial support under the original key. `cedar` demonstrates missing incident attribution. `linen` and `ochre` show cross-technique assignment of evidence. `ash` hybrid cited the outcome and action for T1490 but assigned the hostile attribution to a different technique. These patterns do not reveal the model's internal reasoning.
2. **Reference coverage shortfall.** Five expected occurrences were missing in both arms. Fusion added no keyed top-five occurrence relative to BM25 and demoted `birch`. The generator was allowed to use other active IDs, but all 193 selected technique claims were from the supplied lists. This is strong descriptive evidence of shortlist dependence. Causal anchoring remains a hypothesis because swapping candidates also changes the material available to the model.
3. **Failure to use negative evidence and abstention.** Both arms reported on both failed-action cases in both passes. `flint` hybrid cited an examiner's explicit lack of corroboration for a clearing claim. `silver` hybrid reported the correct role-grant mechanic without establishing hostile control, despite the same-tenant and time-matched authorization. `larch` contains genuine captured content and unresolved source identity. These are distinct failures of outcome, evidence polarity and attribution.
4. **Prompt and response design plausibly contribute.** The system prompt explicitly requests completed adversary behavior, joint records, exact evidence and abstention, so omission of these instructions is ruled out. Its single generation does incident reconstruction and technique selection in one step. Flat pairs permit independent rows, with neither a per-claim evidence group nor a supported/uncertain decision that has to precede technique selection. The schema admits all 18 keyed witnesses and every response achieved contract success. No structural impossibility or recorded truncation explains the observed rate. Whether a grouped answer would improve performance remains untested.
5. **Response variation changes individual costs.** BM25 changed raw text/citations on `indigo`; hybrid changed `indigo` and `silver`. Exact request payloads matched across passes. Within-arm raw agreements were 17/18 and 16/18. Neither variation changed the completed-group count. [Raw evidence and per-case diagnoses](../eval/reports/attack_forensics_v3_20261120/matrix.md)

## 2. Retrieval and description audit

BM25 uses field weights 2.0 for name/ID/aliases, 1.0 for description and 0.35 for context. It takes each candidate's maximum score over the concatenated case and each full record. E5 takes one concatenated query and indexes passage title, description and detection strategy names. Reciprocal rank fusion sums `1/(60 + rank)` for each input rank through 100 with equal weight. The five selected public definitions are presented in case-ID hash order, independent of retrieval rank. The replay verified that all presentation slots reproduce.

## 3. Evaluation and rubric audit

**Technique judgments.** The pinned Enterprise 20.1 definitions support the event-log clearing, forwarding, capture, availability-impact encryption and recovery-inhibition distinctions. `birch` directly supports a tenant role grant and unauthorized control. `quartz` is weaker because East/West roles and an administrator grant do not unequivocally establish a cloud platform. Its session timing and tenant/zone matching matter. The stricter T1098.003 subtechnique should be conditional on the cloud premise. `coral` provides impact through unavailable files and extortion context. `ash` and `slate` link purge completion to loss of recovery points. Inferring an ultimate motive is less certain than identifying the effect. `ochre` correctly allows an independent alternate capture of the same configuration. There are other supporting spans, including corroborating audit sequence and mail delivery, which may deserve explicit partial relevance without replacing the actor/authorization link.

**Decision scope.** The rubric measures completed, attributable adversarial activity. An observed technical mechanism can be real in a benign, failed or inconclusive case. ATT&CK descriptions can discuss attempts or abstract behaviors. In this study the authorized action itself earns no adversary-mapping credit. The same rule needs to appear in any comparative benchmark interpretation. Thin activity or ownership assertions in fictional prose provide a different challenge from ambiguous raw telemetry.

**What the counts mean.** Technique-selection credit can coexist with a missed founded event. Unsupported claims are counted once per technique per cell. Every unsupported citation adds its own cost, so more weak pointers can compound the penalty. Incomplete correct IDs can simultaneously count as unsupported claims and missed groups. The record-pair metric uses a chosen reference group and credits an address within its constituent record. Group completeness still requires every keyed statement. An unkeyed address lacks rubric support, with no independent human judgment of entailment. The disaggregated counts are the preferred interpretation. Arbitrary weights do affect the size of the difference. In this run the pass-one increase in total hybrid cost is `8 × unsupported weight + 8 × bad citation weight`; in pass two it is `9 × unsupported weight + 7 × bad citation weight`. Miss and invalid weights cancel in both passes. Positive weights on either component keep the observed direction. The registered family interval [−2.944, +0.778] remains inconclusive.

**Reproduced scoring defect and correction.** The original aggregate sums all numeric and Boolean values on the result envelope. A valid one-row abstention at pass 2 with an added `latency_ms=47` emits those metadata fields as counts. The v3 report projects onto explicit score fields. Both the minimal regression and complete archived replay confirm that substantive metrics match. The defect does not account for 0/10. The separate model-free structural screen rejected 177 of 193 historical claims based on fewer than two resolved source addresses from distinct record IDs. The 16 remaining candidates were still unsupported by the original rubric. This necessary-condition screen cannot identify semantic support and is specific to this joint-evidence cohort. [Projected metrics and screen results](../eval/reports/attack_forensics_v3_20261120/offline-secondary.json) · [Regression tests](../tests/test_attack_evidence_guard_v3.py)

**Dataset limits.** Nine positives and nine negatives/ambiguous items support contrasting failure modes. Six families share operational motifs and language. Two passes reuse each individual case, so they are repeatability measurements. The 18 cases contain only ten target occurrences across six IDs, one multi-technique case and one sufficiency alternative. English analyst-written summaries contain direct cues such as “intruder,” “refused,” and authorization updates. There are no real source independence attestations, operational prevalence estimates or independently validated labels. The architecture needs independent adjudication before conclusions extend beyond these fictional records. [Full case interpretations](../eval/reports/attack_forensics_v3_20261120/matrix.md)

## 4. Engineering correction and architectural decision

The v3 guard accepts a v2-shaped proposal plus **separately supplied analyst-reviewed normalized facts**. It checks a supported mechanic and objective, completion for the scoped event/session, independent adversary attribution, authorization and process linkage where needed. Trusted disconfirming facts can veto a claim even if the proposal omitted them. An unrelated technique or pointer is rejected per claim. A passing claim is only eligible for analyst review. Trusted normalization, source independence, event windows, authority to supply facts, and corroboration are preconditions of this function. The guard does not derive or authenticate them and is not wired to production. Its scope is six technique mechanics. The v2 eight-entry proposal contract also limits possible simultaneous findings and adapters should validate feasibility at this boundary.

| Option | Evidence and decision |
| --- | --- |
| Single-pass mapping with a deterministic structural check | Useful as a frozen baseline. The retrospective check would screen most unsupported historical hypotheses and leave a residual. It cannot repair missing groups or corroborate labels. |
| Staged evidence analysis with one local model | Preferred next architecture to test. Identify incident facts and contrasts, resolve scoped actor/asset/event links, retrieve candidate definitions by event, and assemble evidence with a deterministic guard before analyst review. Keep the model's proposed fact layer unverified until independent checks. |
| Larger model or multiple model agents | No evidence yet that either is the limiting intervention. Fixing retrieval availability and testing fixed-technique reasoning can be done on the existing local model. This run does not justify paid cloud scaling. |

Targeted Python tests **48 passed**. The full test directory passed **265 with 81 warnings in 20.07 seconds**. Regressions cover authorization, contradiction, supersession, objective mismatch, missing attribution, unrelated technique, wrong host/tenant/time/process links, independent techniques, extra unsupported findings, and empty results. The tests evaluate authored facts, not raw log extraction or classification improvement. ## 5. Executive decision

1. **Why zero complete groups?** Some IDs were absent, and every correct ID shown was returned with missing or misassigned statements. The outputs failed to connect mechanics to incident attribution, authority or outcome.
2. **How much was retrieval?** Five of ten BM25 misses and six of ten hybrid misses were associated with absent references per pass. The counterfactual recovery rate is unknown.
3. **What failed with the correct reference?** All five BM25 and all four hybrid selected positives still lacked a complete group per pass.
4. **Is the rubric defensible?** It is traceable for an exploratory completed-adversary task. T1098.003 on quartz is conditional, and corroboration and source semantics need independent review. Score weights describe this experiment's priorities.
5. **Is 7B fundamentally insufficient?** This run establishes a failure of this deployed configuration on this cohort. It cannot separate model capability from reference availability, response design or context effects.
6. **Next experiment?** Request authorization for A's ten exact local payloads. Compare unchanged hybrid prompts with a fixed-slot candidate-only oracle substitution on five cases. Follow with fixed-technique contrasts to isolate evidence use.
7. **What can be corrected now?** Metric projection, conservative linkage and opposition checks, and explicit abstention handling are implemented and tested offline.
8. **What demonstrates dependability?** Separately verify facts and evidence links on fresh, independently adjudicated telemetry. Measure positive group recall, abstention specificity, unsupported release, multi-event feasibility, and reproducibility with pre-agreed acceptable error rates. Treat the existing 18 cases as development material.
9. **Spend on a cloud model?** The evidence favors resolving the known local design confounds before making a resource decision.
10. **Strengths and limits?** The run is auditable down to original requests, scores and ordered references. Joint-evidence tests expose failures that technique accuracy misses. The small synthetic cohort, AI labels, single model and limited repetition constrain any external inference.
